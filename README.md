# 🏋️ Faper Trainer

Aplicación de entrenamiento con voz para Linux (y futuro Windows).

## 🔊 Características

- Entrenamiento por rondas
- Temporizador con cuenta regresiva
- Voz IA usando Piper TTS
- GUI simple tipo pantalla de gimnasio
- Botón START / STOP

## 🚀 Cómo ejecutar

```bash
git clone https://github.com/lexhoklon/faper-trainer.git
cd faper-trainer
source .venv/bin/activate
python gui.py

## Requisitos
Python 3.10+
Piper TTS instalado
ALSA / aplay funcionando
